# 토리의 생활 순서도

초등학교 5학년이 일상생활 속 상황을 순서도로 나타내 보며 **순차 · 반복 · 선택**을 익히는 웹앱입니다.

## 상황 구성

| 상황 | 흐름 | 내용 |
|---|---|---|
| 1. 양치하기 | 순차 | 치약 짜기 → 이 닦기 → 컵에 물 받기 → 입 헹구기 → 칫솔 씻기 |
| 2. 화분에 물 주기 | 반복 | 화분 10개에 물 주기 (처리 기호 3개까지) |
| 3. 외출 준비 | 선택 | 비 오는 날은 우산, 맑은 날은 모자 |
| 4. 받아쓰기 채점 | 반복 + 선택 | 8문제를 맞았는지 판단해 동그라미 또는 빗금 |
| 5. 분리수거 | 종합 | 바구니가 빌 때까지 꺼내서 플라스틱·종이·일반 쓰레기로 분류 |

## 기능

- 순서도 기호를 누르면 작업판에 기호가 생기고, 칸에 내용을 직접 입력 (회색 예시 글씨 제공)
- 입력 도우미: 상황에 필요한 말과 필요 없는 말을 섞어 제시
- 실행하면 토리가 순서도대로 움직이고, 잘못된 부분을 장면과 메시지로 알려 줌
- 여러 경우(날씨, 시험지, 바구니)를 하나의 순서도로 모두 해결해야 정답
- 틀린 횟수에 따라 생각 힌트 → 구조 힌트 → 거의 정답 → 모범 답안 순으로 도움 제공
- 선생님 모드: 모든 상황 열기, 모범 답안 보기
- 진행 기록은 브라우저(localStorage)에 저장

## 사용 방법

설치가 필요 없는 HTML 파일 하나입니다. `index.html`을 브라우저로 열거나 GitHub Pages로 게시하면 됩니다.
